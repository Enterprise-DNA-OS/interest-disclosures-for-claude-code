# /weekly-review

Read CLAUDE.md. Run `npm run interests -- weekly-review`. All CLI commands support `--json`.

Present the returned records and the date of the snapshot. Name missing data explicitly. Never infer a legal finding from an empty queue.

Combine declaration-rounds, review-queue and mitigation-due, plus attention. Report missing returns, stale assessments, named action owners and the next review dates. Draft committee minutes only from supplied decisions.
