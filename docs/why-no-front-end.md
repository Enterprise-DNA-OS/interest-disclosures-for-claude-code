# Why no front end

The free version is a trusted operator’s disclosure desk. A coding agent reads and changes the records through one CLI. A committee receives private HTML snapshots and documents. The work is rounds, returns, assessments and action follow-up, so those records are useful without a web application.

A browser application adds employee self-service, authenticated reviewers, form branching, mobile capture and live status. This build supplies none of those interfaces. Local access can work offline after dependencies are installed; a remote coding agent or shared database still needs its connection. There is no drag-and-drop document upload or online collaboration.

The generated views are read-only files. Anyone given a file can read its contents, so keep it private. Rerun the report after records change. Enterprise DNA builds the agreed forms, access controls, identity connections or a different stack as part of a customised system. The free database remains useful for the authorised operator who records decisions and prepares the committee pack.
